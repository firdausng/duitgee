# Expenses

An expense is the core record. Each one belongs to exactly one vault and is implicitly in that vault's currency.

## Anatomy of an expense

| Field | Required | Notes |
|---|---|---|
| Amount | Yes | Vault currency. Negative = a refund. |
| Category | Yes | One per expense. Falls through to free-form if not in the catalog. |
| Date | Yes | Stored as UTC; displayed in your local timezone. |
| Paid by | No | One member, or "Vault" (shared / no specific payer). |
| Payment type | No | cash, debit, credit, transfer, e-wallet, QRIS, check, other. |
| Note | No | Free text. |
| Tags | No | Many-to-many vault-scoped labels. |
| Fund | No | Deducts from the chosen [fund](/docs/funds) on save. |
| Attachments | No | Images / PDFs. 5 on Free, 20 on Pro. |

There is **one `paidBy` per expense, not a list of participants** — DuitGee is not a per-expense split tool.

## Adding an expense

Three paths:

1. **Form** — `/vaults/<id>/expenses/new` for the full form, or **Add expense** from the vault home for the quick path.
2. **Receipt scan** — drop a photo or PDF and let the AI prefill the form. Pro feature. See [AI receipt scan](/docs/ai-receipt-scan).
3. **CSV import** — bulk add hundreds or thousands at once. Pro feature. See [Import & Export](/docs/import-export).

## Editing

Open an expense and tap **Edit**. Permissions: only Owner and Admin can edit. Members can only create.

If the expense was generated by a [recurring rule](/docs/recurring), you can edit just that occurrence, or use **Apply to past** when editing the rule itself to propagate amount / category / note / fund changes back through every prior occurrence (fund balances are re-wired in the same write).

## Deleting

Soft delete only. The row keeps its history; statistics and exports skip it. Owners and Admins can delete.

If you delete a recurring rule with **Also delete generated expenses**, every expense it created is soft-deleted in the same operation, and any matching fund transactions are reversed so balances stay honest.

## Duplicate detection

When you save a single new expense, DuitGee checks for existing **unidentified** expenses with a matching amount within ±1 day, regardless of who paid. If it finds one, you get a prompt: *"Claim Sarah's RM 50 from Mar 12?"* The system never auto-merges — magical when right, painful when wrong. See [Unidentified expenses](/docs/unidentified-expenses).

## Filtering and grouping

The expense list at `/vaults/<id>/expenses` supports:

- Date range
- Category
- Member (paid by)
- Payment type
- Tag
- Fund
- Free-text note search

The same filters drive [CSV export](/docs/import-export).

## Notes on shared vaults

- Every active member sees every expense, regardless of who paid.
- Vault-level expenses (`paidBy = null`) count toward the pool but aren't credited to any individual in the [member breakdown](/docs/statistics).
- Member roles control who can edit and delete. See [Roles & permissions](/docs/permissions).
